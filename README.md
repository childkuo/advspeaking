# 如果跟我這樣說.....（300 字完整短文 ＋ 國中 CEFR A2 英文版）

專為**國中生、高中生、家長與師長**打造的**「如果跟我這樣說.....」**雙語對話整理網站。
只需輸入 1～2 句口語白話情境，系統即自動補足**不超過 300 字的完整 5D 結構中文短文**，並同步產出**台灣國中程度（CEFR A2）英文翻譯、核心單字卡與英語發音朗讀**，100% 離線可用。

## 核心特色

1. **口語白話 → 自動整理「如果跟我這樣說.....」≤ 300 字完整短文**
   * 涵蓋 3C 熬夜作息、親子情緒溝通、段考課業誠信、補習晚歸安全、零用錢課金消費、同儕社群與手足衝突、物品與隱私界限、家務自理、通學交通安全等 9 大生活場景（支援複合情境融合）。
   * 內建即時字數監控（`XXX / 300 字 ✓`）與智慧精簡排版，確保每篇短文自然串連 **D1 發生經過 → D2 當下處置 → D3 背後真因 → D4 改善補償 → D5 共同約定**，嚴格不超過 300 字。
2. **台灣國中程度英文翻譯（CEFR A2 單字字彙庫 ＋ 語音朗讀）**
   * 全篇英文採用國中基礎字彙與清晰短句（如 `stay up late`, `calm`, `stress`, `living room`, `alarm clock`, `hand in`, `say sorry`, `respect` 等）。
   * 內建互動式 A2 核心單字卡與 Web Speech API 發音，支援**正常語速（1.0x）**、**慢速跟讀（0.78x）**與**點擊單字即時發音**。
3. **桌機單畫面零捲動 ＋ 手機原生底部 4 分頁導覽**
   * **桌機版**：鎖定 `100dvh` 左右雙欄工作台，左側固定口語輸入與補充微調、右側 7 分頁畫布原地切換，免上下捲動。
   * **手機版**：底部 4 分頁拇指導覽列（`輸入`、`中英短文`、`補一句`、`A4 / 匯出`），搭配 40–48px 觸控按鈕、16px 防 iOS 自動縮放輸入框與安全區適配。
4. **語氣切換、口語再補一句與雙向結構同步**
   * 支援 **溫和親子／青春自律／師長輔導** 三種語氣一鍵切換。
   * 支援再補一句白話（如「其實事後有主動道歉」「約定晚上 11 點放客廳充電」）即時重寫中英雙語短文，亦可點進 D1–D5 個別修改後按「依結構重組」同步更新。
5. **雙軌引擎與隱私資安設計**
   * 預設 100% 離線內建雙語引擎（免 API Key、資料僅存本機 `localStorage`）；選填 Google Gemini API（`x-goog-api-key` Header，不寫入本機）與本機 Ollama（`localhost:11434`），失敗或逾時（30 秒）自動降級回離線引擎。
   * 嚴格 `Content-Security-Policy`（無 inline script / event handler）、`escapeHtml`、`sanitizeFilename` 與原型鏈污染防禦。
6. **多元正式雙語輸出**
   * 「如果跟我這樣說.....」A4 雙語短文與親筆簽名約定單（列印 / PDF）、Word（`.doc`）、16:9 雙語 PowerPoint（`.pptx`，支援 PptxGenJS 與零依賴內建 OOXML 產生器）。

## 快速使用與部署

* **離線開啟**：下載本專案後直接雙擊開啟 `index.html` 即可完整使用。
* **GitHub Pages**：於儲存庫 **Settings → Pages** 選擇 `main` 分支根目錄（`/ (root)`）即可啟用線上靜態網站（`https://childkuo.github.io/advspeaking/`）。
