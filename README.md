# 5D 青春對話小幫手（國高中生活情境・白話語意自動補完版）

專為**國中生、高中生、家長與師長**打造的 5D 結構化對話與生活公約網站。
將 5D 問題解決法升級為**「白話一句話 → 語意自動補完完整初稿 → 單畫面零捲動微調與簽認」**，100% 離線可用，同時支援桌機單畫面雙欄工作台與手機原生底部 4 分頁拇指導覽。

## 核心特色

1. **白話情境自動語意補完（9 大國高中領域＋複合情境融合）**
   * 涵蓋 3C 熬夜作息、親子情緒溝通、段考課業誠信、補習晚歸安全、零用錢課金消費、同儕社群與手足衝突、物品與隱私界限、家務自理、通學交通安全等 9 大青春期真實場景。
   * 支援同時辨識「主領域＋關聯領域」（例如：熬夜滑手機＋甩門頂嘴），自動融合補齊 D1–D5 全框架並產出「初步完整陳述總覽」。
2. **桌機單畫面零捲動 ＋ 手機原生底部導覽**
   * **桌機版**：鎖定 `100dvh` 左右雙欄工作台（左側固定白話輸入與口語微調、右側 7 分頁畫布原地切換），免上下捲動網頁。
   * **手機版**：底部 4 分頁拇指導覽列（`輸入`、`5D 初稿`、`口語微調`、`A4 / 匯出`），搭配 40–48px 觸控高度、16px 防 iOS 自動縮放輸入框與安全區適配。
3. **三態視覺來源標記（兼顧效率與信任）**
   * `原文事實`：由使用者白話直接萃取的人、事、時、地、物與影響。
   * `語意補完`：系統依國高中生情境推演的建議初稿（D2–D5 各提供 3 組「換個建議」並可直接原地編輯）。
   * `已確認`：使用者編輯或透過口語補充確認定稿的內容。
4. **三種表達語氣一鍵切換**
   * **溫和親子對話版**／**青春期自律成長版**／**師長輔導紀錄版**，切換語氣時僅更新尚未確認之語意補完初稿，完整保留原文事實與手動修改。
5. **口語追加微調**
   * 直接再補一句白話（如「其實事後有主動道歉」「真正原因是段考壓力太大」「我們約定晚上 11 點放客廳充電」），系統自動歸類融入對應 D1–D5 欄位並跳轉顯示。
6. **雙軌引擎與隱私資安設計**
   * 預設 100% 離線內建語意補完，資料僅存於瀏覽器 `localStorage`；選填 Google Gemini API（`x-goog-api-key` Header，不寫入本機）與本機 Ollama（`localhost:11434`），失敗或逾時自動降級回離線引擎。
   * 嚴格 `Content-Security-Policy`（無 inline script / event handler）、`escapeHtml`、`sanitizeFilename` 與原型鏈污染防禦。
7. **多元正式輸出**
   * 單頁 A4 親筆簽名報告預覽與列印／PDF、原生 Word（`.doc`）、16:9 PowerPoint（`.pptx`，支援本機 PptxGenJS 與零依賴內建 OOXML 產生器）。

## 快速使用與部署

* **離線開啟**：下載本專案後直接雙擊開啟 `index.html` 即可完整使用。
* **GitHub Pages**：於儲存庫 **Settings → Pages** 選擇 `main` 分支根目錄（`/ (root)`）即可啟用線上靜態網站（`https://childkuo.github.io/advspeaking/`）。
